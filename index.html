📱 iPhone'da Dosyalar (Önizleme) JavaScript'i Engelledi

iOS'un dahili Dosyalar (Files) önizlemesi güvenlik nedeniyle yerel HTML dosyalarında JavaScript çalıştırmaz. Uygulamayı iPhone'da tam etkileşimli açmak için:

  1. Documents (by Readdle) veya HTML Viewer Q (ücretsiz) uygulamalarından birini kurun → Dosyalar'da bu dosyaya basılı tutup Paylaş → Documents / HTML Viewer Q seçin (tamamen çevrimdışı çalışır).
  2. Veya Mac'te klasörde yerel sunucu açıp aynı Wi-Fi'dan iPhone Safari ile açın (Ana Ekrana Ekle ile uygulama gibi sabitlenir).
